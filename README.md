## ⚡ Agent Architecture Workflow

```mermaid
flowchart LR
    User([👤 User / Trigger]) --> Gateway[🛡️ Agent Gateway]
    Gateway --> Planner{🧠 Planner & Reasoning Engine}
    Planner -->|Decompose Goals| Memory[(💾 Vector & Episodic Memory)]
    Planner -->|Dispatch Sub-tasks| ToolEnv[⚙️ Tool & Function Execution]
    ToolEnv -->|MCP / Web / APIs| Action[⚡ External Action]
    Action --> Critic[🔍 Self-Correction / Reflection]
    Critic -->|Refined Result| Planner
    Critic -->|Final Verified Output| User
```
